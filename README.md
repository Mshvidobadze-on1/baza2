# საქართველოს შინაგან საქმეთა სამინისტრო — მონაცემთა ბაზა (baza2)

სრული საძიებო სისტემა ~4.9 მილიონი მოქალაქის ბაზაზე:
- სწრაფი ძებნა სახელით, გვარით, მამის სახელით, პირადი ნომრით, მისამართით და მოწმობის ნომრით.
- პიროვნების და მამის ფოტოების ჩვენება.
- პიროვნების პირადი საქმის (დოსიეს) გენერირება და PDF ბეჭდვა.
- ოფიციალური ადმინ პანელი (ფოტოების ატვირთვა, მობილურის ნომრების, მისამართების და მონაცემების მართვა).

## გაშვება (Getting Started)

```bash
# 1. ინსტალაცია
npm install

# 2. ბაზის აგება (პირველ ჯერზე ავტომატურად ეშვება build-ისას)
npm run build

# 3. სერვერის გაშვება
npm start
```

სერვერი გაეშვება `http://localhost:3000`-ზე.
